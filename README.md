# Siddhant Dubey — Personal Developer Portfolio

> Building things, learning deeply, and documenting the journey.

A modern, interactive developer portfolio featuring 3D animations, custom interactions, and clean responsive design.

## Features

- **3D Interactive Visuals:** Dynamic 3D card tilt & flip, interactive laptop terminal, and physics-driven animations with GSAP ScrollTrigger.
- **Tech Stack & Interests:** Python, NumPy, pandas, HTML, CSS, JavaScript, Git & GitHub, Linux / Arch Linux, and AI/ML experiments.
- **Interactive Capabilities:** Accordion details and project previews.
- **Direct Contact:** Integrated Gmail compose and social links.

## Quick Start

To run the portfolio locally:

```bash
# Start the local server
node server.js
```

Then open `http://localhost:3000` in your browser.
